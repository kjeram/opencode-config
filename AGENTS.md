# Opencode Configuration

**This root folder is designated for storing the `opencode` configuration folder.**

## Important
- The **`opencode` folder should always be used** when making changes to the Opencode configuration.
- Do not make direct modifications to files in the root folder.
- All settings, customizations, and agent configurations belong in the `opencode` directory.
