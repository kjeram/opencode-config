# Productivity Commands

Explicit command entry points for general workflow tools. These commands generally load the corresponding skill to perform the work.

- **[grill-me](./grill-me.md)** — Interview through a plan or design without creating project documents.
- **[handoff](./handoff.md)** — Write a concise handoff for another agent or session.
- **[teach](./teach.md)** — Teach a concept or skill across sessions.
- **[to-questionnaire](./to-questionnaire.md)** — Prepare a questionnaire for someone who can resolve a decision.
