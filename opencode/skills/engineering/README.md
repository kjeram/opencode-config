# Engineering

Engineering workflows and reference material for code work.

## Skills

### User-invoked

Explicit workflows, hidden from automatic skill discovery and reached through their command or a user mention.

- **[ask](./ask/SKILL.md)** — Route a situation to the right engineering workflow.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Interview through a plan or design while recording agreed terminology and durable decisions.
- **[implement](./implement/SKILL.md)** — Implement work described by a spec or ticket.
- **[implement-spec](./implement-spec/SKILL.md)** — Implement a complete spec by coordinating its ticket graph.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — Find codebase deepening opportunities and explore a chosen candidate.
- **[retro](./retro/SKILL.md)** — Suggest improvements to the agent environment after a coding session.
- **[setup-skills](./setup-skills/SKILL.md)** — Configure the repository's issue tracker, triage labels, and domain-doc layout.
- **[to-spec](./to-spec/SKILL.md)** — Turn the current conversation into a spec and publish it to the issue tracker.
- **[to-tickets](./to-tickets/SKILL.md)** — Split a plan or spec into tickets with explicit blocking relationships.
- **[triage](./triage/SKILL.md)** — Move issues and external pull requests through a triage workflow.
- **[wayfinder](./wayfinder/SKILL.md)** — Map and resolve decisions for a large multi-session effort.

### Model-invoked

Discoverable by the agent when their descriptions match the current task.

- **[code-review](./code-review/SKILL.md)** — Review changes against repository standards and the originating spec.
- **[codebase-design](./codebase-design/SKILL.md)** — Design deep modules with small interfaces, clean seams, and testability.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)** — Run a disciplined diagnosis loop for hard bugs and performance regressions.
- **[domain-modeling](./domain-modeling/SKILL.md)** — Sharpen domain language and maintain glossaries and ADRs.
- **[pr](./pr/SKILL.md)** — Shape a pull request body with a clear summary, evidence, and merge-risk call.
- **[prototype](./prototype/SKILL.md)** — Build a throwaway prototype to answer a design question.
- **[research](./research/SKILL.md)** — Investigate a question against primary sources and capture cited findings.
- **[tdd](./tdd/SKILL.md)** — Build behavior test-first with a red-green-refactor loop.
- **[wizard](./wizard/SKILL.md)** — Generate an interactive wizard for steps only a human can perform.
