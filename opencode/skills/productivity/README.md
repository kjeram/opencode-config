# Productivity

General workflow tools that are not specific to code work.

## Skills

### User-invoked

Explicit workflows, hidden from automatic skill discovery and reached through their command or a user mention.

- **[grill-me](./grill-me/SKILL.md)** — Sharpen a plan, decision, or idea without creating project documents.
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff for another agent or session.
- **[teach](./teach/SKILL.md)** — Teach a concept or skill across sessions using a stateful workspace.
- **[to-questionnaire](./to-questionnaire/SKILL.md)** — Prepare a questionnaire for someone who can resolve a decision.
- **[wait-what](./wait-what/SKILL.md)** — Re-pitch a message that did not land, in plain language.

### Model-invoked

Discoverable by the agent when their descriptions match the current task.

- **[grilling](./grilling/SKILL.md)** — Reusable interview discipline for resolving a plan's design tree.
- **[writing-for-agents](./writing-for-agents/SKILL.md)** — Write skills and other documents agents consume.
